# Nordens Paris ⚔️

Dansk guild i **WoW Forever**. Her samler vi de tools og addons, som folk i guilden laver, så alle kan bruge dem.

## 🛠️ [nordens-paris/tools](https://github.com/nordens-paris/tools)

| | |
|---|---|
| **WoW Queue Watcher** | Holder øje med login-køen og sender alarm til din telefon, når det er din tur |
| **UI-overførsel** | Flytter addons, keybinds, macros og Edit Mode fra betaen til din nye character |

**[Hent dem under Releases →](https://github.com/nordens-paris/tools/releases)**

## Vil du være med?

Har du lavet et addon eller et tool, også hvis det er vibecodet med AI? Send dit GitHub-brugernavn til Darkfade på Discord, så bliver du inviteret. Læs [guiden til at bidrage](https://github.com/nordens-paris/tools/blob/main/CONTRIBUTING.md).

Fejl og idéer: [opret et issue](https://github.com/nordens-paris/tools/issues/new/choose) · Spørgsmål: [Discussions](https://github.com/nordens-paris/tools/discussions)
